# ربط قاعدة الموظفين (خاص)

هذه الواجهة الخلفية تعرض **رقم الموظف والاسم والصفة فقط**، ولا تعرض الرواتب. بيانات الموظفين لا تُرفع إلى GitHub.

## التشغيل محلياً

1. ثبّت Python 3.10+ ثم `pip install -r backend/requirements.txt`.
2. أنشئ مجلد `private` في جذر المشروع، وضع داخله `hr_employees_import.sqlite` (ملف قاعدة البيانات الذي تم إنشاؤه من Excel).
3. عيّن متغيرات البيئة `HR_ADMIN_TOKEN` لقيمة سرية طويلة، و`HR_FRONTEND_ORIGIN` إلى عنوان واجهة الموقع المنشورة (مثل `https://firasshafeek21-commits.github.io`).
4. شغّل `uvicorn backend.app:app --host 127.0.0.1 --port 8000`.
5. نقطة الفحص `GET /health`، ونقطة الموظفين `GET /employees` تتطلب ترويسة `X-Admin-Token`.

## تنبيه أمني
هذا تكامل أولي **للإدارة فقط** وليس نظام دخول وصلاحيات كامل. لا تضع رمز الإدارة في JavaScript أو GitHub Pages، ولا تعرض واجهة API للعامة قبل بناء تسجيل دخول وصلاحيات مستخدمين حقيقية وخادم HTTPS. يحتاج نشر الواجهة على الإنترنت إلى استضافة للخادم وقاعدة البيانات بصورة خاصة. لم يتم نشر الخادم أو تثبيت قاعدة البيانات عليه بعد.
