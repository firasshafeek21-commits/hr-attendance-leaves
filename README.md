# نظام إدارة الموظفين والحضور والإجازات

واجهة أولية عربية (MVP) لنظام شؤون الموظفين.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو انشر المستودع باستخدام GitHub Pages.

## الوظائف في هذه النسخة التجريبية
- لوحة رئيسية عربية.
- إنشاء طلب إجازة باسم الموظف ونوع الإجازة والتواريخ والسبب.
- انتقال الطلب إلى المدير للموافقة أو الرفض.
- الطلب الموافق عليه يظهر في صندوق المحاسب.
- حفظ بيانات العرض محلياً في المتصفح باستخدام localStorage.

## تنبيه مهم
هذه نسخة واجهة تجريبية وليست نظام إنتاج بعد. اختيار الدور في الواجهة ليس تسجيل دخول آمناً، وبيانات localStorage موجودة على نفس الجهاز والمتصفح فقط. لا تستخدم بيانات موظفين حقيقية أو حساسة في هذه النسخة.

## مراحل التطوير التالية
1. قاعدة بيانات مركزية وواجهة API.
2. تسجيل دخول آمن وصلاحيات حقيقية للموظف والمدير والمحاسب ومسؤول النظام.
3. ربط جهاز البصمة حسب الشركة والموديل وطريقة الاتصال المتاحة.
4. إشعارات فعلية وسجل تدقيق وتقارير ونسخ احتياطي.
